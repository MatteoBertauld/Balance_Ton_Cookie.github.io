[02] Confidentialité des Données

"Paradoxe détecté : Nous affichons vos données pour vous prouver que nous n'avons pas besoin de votre permission pour les voir, mais nous ne les stockons jamais sur nos serveurs."

// Nature des données traitées

Dans le cadre de cette démonstration, les données suivantes sont extraites de votre navigateur :

  • Empreinte matérielle (CPU, RAM, GPU, Batterie)
  • Données de navigation (Pages vues, clics, temps actif)
  • Adresse IP et géolocalisation approximative

// Finalité du traitement

Ces données sont utilisées uniquement pour un affichage en temps réel sur votre écran à des fins pédagogiques. Aucune donnée n'est revendue à des tiers ou utilisée pour du profilage publicitaire par cet éditeur.

// Durée de conservation

Les données comportementales (clics, refresh) sont stockées dans votre propre navigateur via LocalStorage. Vous pouvez les effacer à tout moment en vidant votre cache.
